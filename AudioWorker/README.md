\# Meeting Optimization AI



This project analyzes meeting audio recordings to calculate:

\- Total speech duration

\- Total silence duration

\- Speech vs silence ratio



\## Features

\- Voice Activity Detection (VAD) using pyannote.audio

\- Hugging Face pretrained models

\- Works on WAV audio files (16kHz mono recommended)
